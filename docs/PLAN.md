# YA-32-Bot — план переписывания (v1.0.0)

Зафиксировано с владельцем 2026-10-05. Бот расписания для одной группы КПИ (groupId 3655),
только личные сообщения, тексты бота — українською.

## Решения

| Вопрос | Решение |
|---|---|
| Язык бота | Українська |
| Группы | Одна группа (ЯА-32), без multi-tenant |
| Чаты | Только личка |
| БД | PostgreSQL 17-alpine, урезанный конфиг (~25 МБ RAM). Через SQLAlchemy — SQLite одной строкой `DATABASE_URL` (тесты так и гоняются) |
| Старые данные | С нуля, старая Heroku-БД не переносится |
| Источник расписания | Вручную через бота + синхронизация с `api.campus.kpi.ua` (подключаемые источники, `ScheduleSource`) |
| Деплой | Тот же сервер, `/srv/ya32-bot`, образ `ghcr.io/<owner>/<repo>`, CD по тегу `vX.Y.Z` |
| Git | Не инициализируем — репо у друга. Всё готово к `git init` |

## Что меняется относительно старой версии

- `pyTelegramBotAPI` (sync) → **aiogram 3.31** (async, Router, FSM, middlewares, Rich Messages, цветные кнопки).
- Сырые f-string SQL (SQL-инъекции) → **SQLAlchemy 2 async + Alembic**.
- `requirements.txt` (UTF-16) → **Poetry**.
- Токен и пароль БД в коде → **pydantic-settings + `.env`** (токен прежний, просто вынесен из кода).
- Папка в папке + `112.py` → один пакет `src/ya32_bot/` со слоями.
- Глобальные dict-кэши → БД — единственный источник правды.
- `/add_one_adm` (админ для любого) → роли + одноразовые инвайт-ссылки, владелец из `OWNER_ID`.
- Хардкод каникул (2023) и лет (2021–2025) → семестр, каникулы и чётность настраиваются в боте.
- `setlocale(uk_UA)` → свои украинские названия дней/месяцев (в Docker нет локали).
- Ввод даты `2020:09:22` → inline-календарь.
- Legacy Markdown + Reply-клавиатуры → HTML/Rich Messages, inline-кнопки со `style`, навигация редактированием одного сообщения.
- Procfile (Heroku) → Dockerfile + docker-compose + GitHub Actions CI/CD.
- Нет тестов/линтеров → `scripts/gate.py` (ruff + mypy strict + bandit + pytest), тот же в CI.
- Нет процесса → `.claude/` (CLAUDE.md, docs, hooks, skills, agents) по образцу Zebaro-Core / Neko / Bento.

## Фичи

1. **Редактор расписания в Telegram** — inline-мастер: день → пара → изменить/перенести/отменить/добавить.
2. **Шаблоны недель (1/2)** + разовые изменения на конкретную дату (override/отмена/добавление).
3. **Синхронизация с КПИ**: «🔄 Дозавантажити» (diff-превью → применить), «♻️ Перезавантажити» (заменить шаблон, ручные правки и ДЗ сохраняются), автопроверка раз в сутки с уведомлением админам о расхождениях. Новый источник = новый класс `ScheduleSource`.
4. **Семестр из бота**: даты, каникулы, чётность (авто из КПИ или вручную).
5. **Inline-календарь** для выбора даты.
6. **Домашка 2.0**: текст + фото/файлы, дедлайн, «✅ зроблено» персонально, список «що задано».
7. **/now** — текущая/следующая пара, сколько осталось до конца/начала, прогресс-бар.
8. **Карточка пары**: тип, преподаватель, аудитория, кнопки-ссылки (корпус, Zoom/Meet/Classroom).
9. **Напоминания** (вкл/выкл каждое): утренний дайджест (время настраивается), за N минут до пары, новая ДЗ, изменения расписания.
10. **Рассылка изменений**: правка на ближайшие 7 дней → «🔔 Зміна в розкладі» подписанным.
11. **Роли по инвайт-ссылкам**: owner / admin / editor (ДЗ) / student.
12. **Inline-режим**: `@bot` в любом чате → сегодня/завтра/неделя для отправки.
13. **Настройки «под себя»**: компактный/подробный вид, показывать преподавателя/аудиторию, выходные, тихие часы.
14. **Журнал правок с «↩️ Скасувати»**, экспорт `.ics`, `/stats` для админа, `/search` по предметам.
15. **Дедлайны**: «🔥 Дедлайни» — ближайшие ДЗ с обратным отсчётом.

## Пасхалки (отдельно)

- `/avatar` или «вода, земля, вогонь, повітря» — анимированное вступление «Аватара» (поклон удалённому `112.py`).
- «кава» во время перерыва — «☕ Перерва ще N хв».
- 32 нажатия «Наступний» подряд — ачивка «ЯА-32 forever».
- Последний день семестра — сообщение с эффектом конфетти.
- Пишешь после 01:00, а завтра пара в 8:30 — «Пара о 8:30. Спати. 😴».
- 7-я пара в пятницу — 💀.
- `/42` — «Відповідь знайдено. Питання — ні.»

## Инфраструктура

- Dockerfile (multi-stage, python:3.13-slim, non-root), healthcheck.
- docker-compose: `ya32-db` (postgres:17-alpine, урезан) + `ya32-bot` (миграции при старте).
- CI: `scripts/gate.py --strict`. CD: тег → gate → GHCR → scp compose → ssh `docker compose up -d`.
- `scripts/`: gate.py, release.py, dev.bat, prod.bat, backup (pg_dump в prod.bat).
- `.claude/`: CLAUDE.md, docs (workflow, conventions, faq), hooks (guard-git, guard-secrets, notify), skills (gate, finish, push, release, idea, playbook, prod), agents (explorer, code-reviewer, test-writer).

## Дополнения по ходу работы

- **Аудитории по умолчанию скрыты** (группе не нужны). Каждый элемент расписания включается
  отдельно в `/settings → 👁 Вигляд`: время, тип, преподаватель, аудитория, ссылки, ДЗ, примечания,
  отменённые пары, окна, номер недели, пустые выходные, короткие названия, компактно, эмодзи,
  новый вид. Пресеты «Мінімум / Стандарт / Все» и предпросмотр.
- **Команды и описание бота обновляются сами**: при каждом старте публикуются из
  `bot/commands.py`; админам — расширенное меню по scope чата (и сразу при смене роли).
- Парсер КПИ сделан как подключаемый источник (`services/sources/`, скилл `/new-source`) —
  другой сайт добавляется одним классом.
- Погоды нет — только расписание, домашка, уведомления и пасхалки.
