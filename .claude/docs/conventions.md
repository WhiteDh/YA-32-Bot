# Конвенции

## Коммиты

- **Одна строка**, английский, повелительное наклонение, `type(scope): summary` — о том,
  что изменилось по сути, а не какой файл тронут:
  `fix(sync): read Tuesday as «Вв» like the KPI API spells it`,
  `chore(release): v0.6.0`.
- Типы: `feat` · `fix` · `docs` · `refactor` · `test` · `chore` · `perf` · `ci`.
- Скоупы: `tg` · `admin` · `sync` · `notify` · `db` · `infra` · `deps` ·
  `tooling` · `changelog`.
- **Автор — человек.** Ни `Co-Authored-By`, ни «Generated with», ни упоминаний ассистента
  и его вендора — нигде: ни в коммитах, ни в тегах, ни в PR, ни в комментариях кода, ни в
  документах. `guard-git` блокирует такой коммит, а `attribution` в `.claude/settings.json`
  выключает приписку на уровне самого инструмента. Слово «AI» в сообщении разрешено: у группы есть
  предмет про штучний інтелект.
- Рабочие заметки, которые читаются как чужой голос («согласовано с пользователем»), в
  git не кладутся — им место в `_temp/` или `_ideas/`.
- Никогда `--no-verify`, `--no-gpg-sign`, force-push, `reset --hard origin`. Тоже
  блокируются.
- Один логический коммит на изменение, и на каждом коммите тесты зелёные.

## Гейт

Единственный чекер — `scripts/gate.py`. Он же CI, и он же первый шаг CD.

```bash
python scripts/gate.py            # всё
python scripts/gate.py --lint     # линт и типы по ходу работы
python scripts/gate.py --strict   # + покрытие, перед релизом
python scripts/gate.py --fix      # ruff --fix + ruff format, потом гейт
```

**Не зови ruff / mypy / bandit / pip-audit / pytest напрямую.** Если
проверка идёт мимо гейта, твоё «зелено» перестаёт совпадать с зелёным CI. Нужен один тест —
`--only pytest -- путь::тест`.

## Версии

Одна, в `VERSION`. `release.py` зеркалит её в `pyproject.toml`, `src/ya32_bot/config.py` и
`src/ya32_bot/__init__.py` (бот пишет её в лог при старте, `tests/test_repo.py` сверяет). Тег `vX.Y.Z` — единственное, что деплоит.

- `patch` — починили; `minor` — добавили; `major` — сломали совместимость (почти никогда).

## CHANGELOG

Пишется **до** релиза, в раздел `## Unreleased`: по-русски, что изменилось для тебя как
пользователя бота. `release.py` проставляет на раздел версию и дату и отказывается
работать с пустым — править заметки после тега значит двигать уже выкаченный тег.

## Секреты и `.env`

- Настоящие значения — только в `.env` (вне git) и в GitHub Actions secrets. Никогда в
  `settings.json`, скриптах или переписке.
- `.env.example` версионируется и содержит **имена** переменных. Добавил поле в
  `src/ya32_bot/config.py` — добавь и туда, и в `docker-compose.yml`, и в `cd.yml`.
- `guard-secrets` блокирует печать `.env`, приватных ключей, полного дампа окружения и
  окружения контейнеров (`docker inspect` без `--format`, `docker exec … env`,
  `docker compose config` без `-q`).

## Зависимости

- **Poetry**, `poetry.lock` коммитится. Гейт проверяет, что он совпадает с `pyproject.toml`.
- Новая зависимость — это решение: скажи, зачем она и что будет без неё.
- Схема БД меняется только миграцией Alembic (`scripts\dev.bat migrate "что"`); применённые
  миграции не правятся — пишется новая. `tests/test_repo.py` ловит модель без миграции.
