# Изменения

Что менялось для группы — по-русски, по версиям. Раздел `## Unreleased` заполняется до релиза;
`scripts/release.py` проставляет на него версию и дату.

## Unreleased

## v1.0.0 — полная переделка

Бот переписан с нуля: новая архитектура, aiogram 3, PostgreSQL, Docker, автодеплой.

**Расписание**
- Сегодня / завтра / неделя / любая дата: inline-календарь, `/day 12.10` или просто `12.10`.
- `/now`: текущая пара с прогресс-баром, следующая пара, перерыв.
- Карточка пары: тип, преподаватель, ссылки на пару, домашка.
- Новое оформление (Rich Messages), цветные кнопки, навигация без лишних сообщений.
- Inline-режим: `@бот` в любом чате, чтобы поделиться днём или неделей.

**Домашка**
- Текст, фото, файлы, голосовые; срок; личная отметка «✅ зроблено»; список с отсчётом.

**Настройки**
- Каждый элемент расписания включается и выключается отдельно (аудитории по умолчанию скрыты).
- Пресеты «Мінімум / Стандарт / Все», компактный вид, короткие названия, предпросмотр.
- Утренний и вечерний дайджест, напоминание за N минут, уведомления об изменениях, новой
  домашке и дедлайнах, тихие часы. Каждое настраивается отдельно.

**Для админов**
- Редактор дня: отменить, изменить, перенести, добавить пару. Группа получает одно
  уведомление об изменениях.
- Шаблон недели 1/2, семестр и каникулы, номер недели, предметы со ссылками.
- Синхронизация с schedule.kpi.ua: дозагрузить / обновить / перезагрузить с превью изменений
  и ежедневной автопроверкой.
- Журнал правок с отменой, объявления, статистика, роли по ссылкам-приглашениям.
- Меню команд бота обновляется само, в @BotFather ничего настраивать не нужно.

**Исправлено относительно старой версии**
- Любой мог стать админом командой `/add_one_adm`.
- В 2026 году бот не принимал даты (жёсткий диапазон 2021–2025).
- Админы терялись после перезапуска; каникулы были прописаны в коде.
- Токен и пароль базы лежали прямо в коде; возможна была SQL-инъекция.

🥚 Внутри пасхалки. `/secrets` подскажет, сколько найдено.
