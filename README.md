# YA-32-Bot 🎓

Telegram-бот расписания группы **ЯА-32 (КПИ)**. Тексты бота — українською.

- 📅 Расписание на сегодня / завтра / неделю / любую дату (inline-календарь, `/day 12.10` или просто `12.10`)
- ⏱ `/now` — какая пара идёт, сколько до конца, что дальше, перерыв
- 🔗 Название предмета в расписании — гиперссылка на пару (Meet / Zoom). Ссылки семестра — `core/links.py` (по предмету, при разных преподавателях — по фамилии); ссылка из админки — запасная
- 📖 Карточка пары: тип, преподаватель, кнопка «🔗 Приєднатися»
- ⚙️ `/settings` — только уведомления: утренний и вечерний дайджест, напоминание за N минут, изменения расписания, тихие часы. Вид расписания одинаковый для всех
- 📚 Домашка (`/hw`) осталась в коде, но кнопок для неё в интерфейсе нет
- 🔎 Inline-режим: `@бот` в любом чате → поделиться днём или неделей
- 🛠 Админка: редактор дня (отменить / заменить / перенести / добавить пару), шаблон недели 1/2, семестр и каникулы, предметы и ссылки, журнал правок с «↩️ отменить», объявления, статистика, роли по ссылкам-приглашениям
- 🔄 Синхронизация с [schedule.kpi.ua](https://schedule.kpi.ua/?groupId=3655): «➕ Дозавантажити», «🔄 Оновити», «♻️ Перезавантажити» с предпросмотром изменений; ежедневная автопроверка
- 🤖 Меню команд и описание бота публикуются из кода при каждом старте — в @BotFather ничего руками не настраивается
- 🥚 Пасхалки (`/secrets` покажет прогресс)

## Стек

Python 3.13 · aiogram 3.31 (Rich Messages, цветные кнопки) · SQLAlchemy 2 async + Alembic ·
PostgreSQL 17-alpine (в тестах — SQLite) · APScheduler · httpx · Poetry · ruff + mypy strict + bandit + pytest.

## Быстрый старт

```bat
copy .env.example .env          :: заполни BOT_TOKEN и OWNER_IDS
scripts\dev.bat install         :: poetry install
scripts\dev.bat                 :: бот локально на SQLite (data/ya32.db)
```

С Postgres как на проде: `scripts\dev.bat infra` (поднимет `ya32-db` с портом 5432 наружу) и
`DATABASE_URL=postgresql+asyncpg://ya32:ya32@localhost:5432/ya32` в `.env`.

Первый запуск:
1. Напиши боту `/start` с аккаунта из `OWNER_IDS` — станешь владельцем.
2. `/admin` → «🔄 Синхронізація КПІ» → «🔍 Перевірити» → «➕ Дозавантажити».
3. «🗓 Семестр і канікули» — проверь начало/конец семестра и номер недели.
4. «👥 Люди й ролі» → «🔗 Запрошення» — ссылки для старосты (редактор ДЗ) и админов.
5. Включи inline-режим в @BotFather (`/setinline`), если нужен `@бот` в чатах.

## Структура

```
src/ya32_bot/
├── core/        чистая логика: звонки, недели, сборка дня, настройки пользователя
├── db/          модели SQLAlchemy, движок, миграции при старте
├── services/    расписание, домашка, люди, журнал/undo, семестр, синхронизация
│   └── sources/ источники расписания (kpi.py — api.campus.kpi.ua)
├── bot/         handlers/ · keyboards/ · render/ · middlewares/ · notify · ui · commands
├── scheduler/   минутный тик (дайджесты, напоминания) и ежедневная проверка КПИ
└── app.py       сборка и запуск (long polling)
migrations/      Alembic
tests/           pytest (SQLite в памяти, фейковый Telegram)
scripts/         gate.py · release.py · approve.py · dev.bat · prod.bat
docs/            PLAN.md · architecture.md · deploy.md
```
